## Penganalisis Ingerens AI Ringkas 
Aplikasi Python ringkas untuk menganalisis data inferens AI.

## Ciri-ciri
Memuatkan data inferens AI daripada fail CSV

Memaparkan lima rekod pertama

Menetapkan ambang keyakinan (confidence threshold)

Menapis rekod inferens berdasarkan tahap keyakinan

Mengira statistik inferens

Mengira jumlah pengesanan mengikut kelas objek

Menjana carta bar bagi jumlah pengesanan objek

## Keperluan Sistem
Python

pandas

numpy

matplotlib

## Cara Menjalankan Aplikasi
Jalankan arahan berikut:

Bash
python main.py
Masukkan nilai ambang keyakinan antara 0.0 dan 1.0 apabila diminta.

Hasil Output
